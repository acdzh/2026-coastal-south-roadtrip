### 路线详情
- **出发**：衢州，上G60沪昆高速
- **途经**：金华 → 义乌 → 东阳 → 诸暨 → 杭州 → 嘉兴 → 上海
- **高速编号**：G60沪昆高速全程
- **到达**：上海

### 驾驶体验提示
- 🟢 **衢州→金华段（0-100km）**：早上出发车少，路况好。
- 🟢 **金华→义乌段（100-170km）**：顺畅，双向六车道。
- 🟡 **义乌→杭州段（170-300km）**：开始汇入杭州方向车流，越接近杭州越堵。
- 🔴 **杭州绕城（300-340km）**：**国庆返程最堵路段**。杭州绕城南线/西线可能堵1-3小时。如果堵死，备选走杭州中环或城区穿过。跟着导航走，实时规避。
- 🔴 **杭州→嘉兴段（340-400km）**：G60沪杭段国庆返程经典堵车路段。下午最堵，上午相对好。
- 🟡 **嘉兴→上海段（400-407km）**：接近上海进入市区后可能有常规拥堵。

## 路上吃的

### 早餐
出发前在衢州买个早餐带上车，或者到金华服务区吃。

### 午餐
- **首选**：嘉兴服务区。浙江最气派的服务区之一，有肯德基、星巴克和本地小吃。如果需要充电可以边充边吃。
- **备选**：金华服务区或长安服务区（杭州段）。
- **车上吃**：提前准备面包、零食、水果，堵车时在车上解决，不浪费时间。

### 充电策略

| 场景 | 建议 |
|------|------|
| 昨晚衢州充满电（95%+） | 407km在续航范围内，可以不充直接回。但堵车开空调会额外耗电，保险起见在金华或嘉兴服务区补20分钟快充。 |
| 昨晚没充满或电量不足 | **必须在金华服务区充电**，充到80%以上再走。 |

## 到家时间预估

以7:00出发为基准：

| 场景 | 到家时间 | 说明 |

> 正常情况下午3-5点到家。即使严重堵车，晚上9点前也能到。10/8上班没问题。关键是**7:00前出发**，不要贪睡。

### 万一堵到崩溃的备选方案
如果中午12点还堵在杭州以西，评估一下：
- **方案A**：继续等。堵车终会过去，晚上到家没问题。
- **方案B**：下高速走国道/省道。杭州以西可以走G320国道，虽然慢但不堵。不推荐，绕路时间更长。
- **方案C**：在杭州或嘉兴找个商场/咖啡店歇几个小时，等晚上6-7点车流减少后再走。适合实在不想堵车的情况。
