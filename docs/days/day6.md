## 路线

<RouteMap :day="6" />

### 路线详情
- **出发**：福州，上G1505福银高速北上
- **途经**：南平 → 武夷山 → 江山 → 衢州
- **高速编号**：G1505福银高速 → G3京台高速
- **下高速**：衢州出口

### 驾驶体验提示
- 🟢 **福州→南平段（G1505，约200km）**：内陆高速，车流量比沈海少得多。双向四车道，路况好。
- 🟡 **南平→武夷山段（G3京台，200-350km）**：闽浙交界山区路段，**隧道30+个**，部分隧道连续成群。提前开灯，保持车距。好消息是国庆走内陆这条路的车很少。
- 🟢 **武夷山→衢州段（G3京台，350-468km）**：出山区后逐渐平坦，进入浙江境内路况好。
- 🏔️ **闽浙山区风景**：G3京台高速穿越武夷山脉，沿途能看到连绵的山峦和茶园。虽然以赶路为主，但风景并不无聊。

### 充电策略

| 充电点 | 位置 | 建议 |
|--------|------|------|
| 南平服务区 | G1505约200km处 | **推荐**。此时电量约60%左右，充到85%即可继续 |
| 武夷山服务区 | G3约300km处 | **备选**。如果南平没充或排队太久，这里补电 |
| 衢州到达后 | 市区充电站 | 过夜充电，补满为明天做准备 |

> [!TIP] 充电建议
> 国庆走京台高速内陆线的车远少于沈海高速，服务区充电排队概率低。但保险起见，电量到40%就找桩充，不要赌到20%。

## 沿途可选（时间充裕才去，否则跳过）

今天以赶路为主。468km需要6-7小时纯驾驶时间，加上充电休息，全天都在路上。沿途没有必去景点，到了衢州后才是休闲时间。

- **武夷山服务区**（如果要充电的话可以顺便逛逛）— 闽北服务区，有当地小吃
- **江山市**（G3京台高速江山出口）— 如果实在太累想歇歇脚，江山有江郎山景区，但不建议今天去，赶路要紧

## 路上吃的

### 午餐方案

**方案A（推荐）：武夷山服务区简单解决**
边充电边吃，不额外浪费时间。闽北服务区有本地小吃和快餐，人均30-50元。

**方案B：带前一晚买的食物车上吃**
如果昨晚在福州买了特产/零食，在车上解决午餐，节省时间。

### 晚餐重头戏：衢州三头一掌

到了衢州终于可以好好吃一顿。衢州是浙江最会吃辣的城市，"三头一掌"是当地灵魂美食：兔头、鸭头、鱼头、鸭掌，又辣又过瘾。

| 项目 | 详情 |
|------|------|
| 吃什么 | 三头一掌（兔头、鸭头、鱼头、鸭掌），衢州本地最有特色的吃法 |
| 人均 | 60-100元 |
| 推荐点法 | 2人点：兔头2个 + 鸭头2个 + 鸭掌1份 + 鱼头半个，再加个青菜。够吃够爽。 |
| 去哪吃 | 到衢州后高德搜"三头一掌"，选评分高的本地店。水亭门附近有不少。 |
| 辣度 | 衢州辣是真辣，不太吃辣的话跟老板说微辣 |
