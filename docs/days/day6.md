## 晚餐：衢州三头一掌

衢州最出名的美食就是"三头一掌" — 兔头、鸭头、鱼头、鸭掌。重辣重味，和武夷山的清淡山菜风格截然不同。

| 项目 | 详情 |
|------|------|
| 推荐区域 | 水亭门附近 / 马站底美食街 |
| 人均 | 50-80元 |
| 推荐点法 | 2人：鸭头4-6个（约5元/个）+ 兔头2个（约8元/个）+ 鸭掌一份（约15元）+ 一个素菜/主食 |
| 特色 | 衢州菜偏辣（浙江唯一吃辣的城市），兔头鸭头是凉的卤制品，配啤酒绝佳 |
| 其他推荐 | 衢州烤饼（葱肉饼，约3元/个）、搁袋饼、肉圆 |
