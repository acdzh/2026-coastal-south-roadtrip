### 路线详情

- **出发**: 从洞头出发，经灵霓北堤出岛
- **上高速**: G1523甬莞高速 → S10温州绕城高速 → G15沈海高速

### 驾驶体验提示

- 🟢 洞头到苍南段：G1523甬莞高速路况好，双向四车道，沿途可以看到乐清湾海景
- 🟡 苍南到福鼎段：跨省路段，隧道开始增多，进入福建后山路弯道渐多，注意限速
- 🔴 G15沈海高速苍南-福鼎段：国庆可能堵车（浙闽省界传统堵点），备选方案：提早在苍南下高速走G228国道到福鼎
- 🏔️ 福鼎到霞浦段：路两侧山海交替，风景开始变得有层次感
- 🚇 苍南-福鼎段连续隧道较多，总长约8km，提前开灯

### 为什么来这里

霞浦是中国滩涂摄影圣地，被《国家地理》列为中国最美海岸线之一。退潮时大片滩涂露出水面，紫菜架、竹竿、渔网在光影中构成天然画卷。即使不是专业摄影师，傍晚的光线和滩涂也足以让人震撼。

### 实操信息

| 项目 | 详情 |
|------|------|
| 地址 | 北岐：霞浦县松港街道北岐村；东壁：霞浦县三沙镇东壁村 |
| 停车 | 北岐山顶观景台有停车场，免费，车位约30个；东壁村路边可停车 |
| 停车坐标 | 高德搜"北岐滩涂观景台"或"东壁日落观景平台" |
| 门票 | 免费 |
| 营业时间 | 全天开放（自然景观） |
| 建议游玩时间 | 1-2小时（傍晚日落前1小时到最佳） |
| 最佳到达时间 | 日落前1-1.5小时（10月初霞浦日落约17:52） |
| 手机信号 | 好 |
| 潮汐影响 | 退潮时滩涂景观最佳，⚠️ 建议出发前查询霞浦潮汐表 |

### 今天看哪个？北岐 vs 东壁

- **北岐**：适合看日出（明天早上来），傍晚也不错但不如日出惊艳。从霞浦县城开车15分钟
- **东壁**：适合看日落，面朝西边，夕阳洒在滩涂上非常壮观。从霞浦县城开车40分钟，在三沙镇方向
- **建议**：今天下午到霞浦后直接去东壁看日落，明天早上去北岐看日出

### 游玩路线建议

1. 下午到达霞浦县城后，先在县城补给（水、零食、充电）
2. 16:30 出发前往东壁村（约40分钟车程）
3. 到东壁后找到观景平台，等待日落
4. 日落后驱车到三沙镇吃晚餐

### 国庆人流预估

- 预估人流：中偏多（霞浦近年知名度上升，国庆摄影爱好者较多）
- 避开人流的技巧：北岐观景台位置有限，日出时段最挤；东壁相对分散，沿村子走能找到人少的位置
