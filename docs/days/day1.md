## 出发策略

### 几点出发？

根据小红书国庆出行经验，10月1日是全年高速最堵的一天。上海南下方向（沪昆高速、沈海高速）从早上7点开始堵，10点达到峰值，一直到下午2点才缓解。

- **方案A（推荐）: 凌晨5:00出发**。赶在6:30前通过嘉兴段，避开最堵的8-12点窗口。预计中午12-13点到三门服务区，下午2-3点到温岭，还有整个下午在石塘玩。
- **方案B: 9/30晚上22:00出发**。夜间跑完全程，凌晨4-5点到温岭，在车上睡到天亮。好处是完全避开堵车；缺点是两人都需要熬夜。
- **方案C: 中午12:00错峰出发**。等堵车高峰过了再走。好处是不用早起；缺点是到石塘已经天黑，第一天基本报废。

**结论：方案A最稳。5点出发，闹钟定4:30。**

### 走哪条路？

**推荐路线：G60沪昆 → G1522常台 → G15沈海 → G1523甬莞**

1. **上海 → 嘉兴段（G60沪昆高速）**：从莘庄收费站上G60，国庆早高峰这段最先堵。5:00出发可以在拥堵前通过。
2. **嘉兴 → 绍兴段（G60转G1522常台高速）**：在嘉兴枢纽转G1522，经过绍兴。这段相对顺畅。
3. **绍兴 → 宁波段（G1522常台高速）**：经过上虞、余姚到宁波。宁波绕城可能有短暂拥堵。
4. **宁波 → 三门 → 温岭段（G15沈海 → G1523甬莞）**：过宁波后转G15沈海南下，经过三门到温岭出口。这段国庆相对不堵。
5. **温岭出口 → 石塘半岛**：下高速后走S226/县道约30km到石塘，用时约40分钟。

**堵车备选：如果G60莘庄方向堵死**
- 备选1：走S32申嘉湖高速，从金山方向绕嘉兴，绕路约30km但可能快1小时
- 备选2：先走G15W常嘉高速到嘉兴再转G1522

**上高速收费站建议**：避开莘庄、枫泾等热门收费站。建议从新桥收费站或松江收费站上G60，人少。

### 为什么来这里

石塘半岛是浙江最有味道的海边渔村之一。石头房子层层叠叠建在山坡上，面朝大海，不像那些被过度商业化的古镇。这里有马卡龙色的七彩小箬村（神似意大利五渔村），有能俯瞰整个石塘镇的对戒观景平台，还有中国大陆第一缕新千年曙光照射地。关键是——全部免费，没有门票。

### 游玩路线建议（自驾串联，全程约3小时）

1. **对戒观景平台**（30分钟）— 先来这里，俯瞰整个石塘镇全景。山下有绿皮火车打卡点和两家悬崖咖啡馆。导航搜"对戒观景平台"。
2. **小箬村**（45分钟）— 马卡龙色七彩渔村，入口在村里的天后宫。从麒麟山顶可以拍到最佳角度，适合看日落。导航搜"小箬村麒麟山"。
3. **金沙滩**（30分钟）— 附近有座灯塔，可以踩踩沙滩走走。导航搜"金沙滩"。
4. **锡安堂**（路过拍照即可，10分钟）— 酷似城堡的教堂，在石塘镇里。如果路上经过顺便看看。

### 国庆人流预估
- 预估人流：**多**。石塘是近年小红书网红地，国庆人会很多。
- 避开人流的技巧：对戒观景平台上午人最多，下午3-4点人流回落。小箬村黄昏时段拍照人多但氛围最好。

## 备选路线：三门方向

> 以下内容来自另一套备选攻略的研究数据。如果第一天不想开那么远（石塘432km vs 三门335km），可以把三门作为 Day 1 目的地，Day 2 再经石塘去洞头。

### 为什么考虑三门

三门比石塘近约100km，国庆首日堵车风险下相当于少开1-2小时。三门有蛇蟠岛（千年采石洞穴奇观）、东屏古村、"小冰岛"矿坑公园等景点，且不是热门旅游城市，国庆人流远低于石塘。三门还是浙江青蟹之乡，10月正是膏蟹最肥的时候。

### 三门核心景点

- **蛇蟠岛**（野人洞+海盗村）：千年采石遗迹形成的海岛奇观，石洞密布。门票约100元/人，游玩2-3小时。停车场免费，可过夜。
- **东屏古村**：三面环山一面向海的清代石头古村落，免费，人少安静。距蛇蟠岛约30分钟车程。
- **"小冰岛"矿坑公园**：废旧矿坑爆改的网红打卡点，碧绿水面配白色岩壁，免费，20-30分钟够了。
- **健跳码头**：三门最大渔港，下午15:00-17:00渔船回港可买刚上岸的海鲜。2人买约140元（1只青蟹+半斤虾蛄+1斤蛏子）。

### 三门美食

- **青蟹汤米面**：三门招牌，人均50-80元
- **清蒸三门青蟹**：10月膏蟹最肥，约80-150元/斤
- **望潮**（小章鱼）、虾蛄、蛏子等小海鲜

### 三门过夜

蛇蟠岛景区停车场（免费，有24小时公厕，无充电桩）。最近充电站在三门县城约20km。

### 三门方向路线数据

上海 → 三门335km，约4.7小时（不含堵车）。走G60沪昆高速 → 嘉绍大桥 → G1522常台高速 → G15沈海高速 → S37三门联络线。

### 过夜 Tips
- 10月1日温岭日落约17:40。建议日落前到过夜点踩好位置。
- 到了先去公厕洗漱，回车上布置睡觉。

### 雨天 B 计划

如果今天下雨：
- **对戒观景平台**：雨天也能去，带伞。云雾中的石塘别有一番味道。但如果大风大雨就不安全，改为车上远观。
- **小箬村**：小雨照常去，拍照反而有氛围感（雨后颜色更鲜艳）。大雨跳过。
- **金沙滩**：雨天跳过，沙滩雨天没什么可看的。
- **午餐/晚餐不变**：都是室内吃饭，不受影响。
- **过夜**：雨天更适合停室内或有遮蔽的停车场。石塘镇上部分停车场有顶棚。如果连续大雨可考虑住一晚民宿，第二天再睡车。
