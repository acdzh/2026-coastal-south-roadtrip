### 为什么来这里

北岐是霞浦最经典的滩涂摄影点，没有之一。山顶观景台正对东方海面，日出时阳光、云彩、滩涂、紫菜架构成的画面，是很多摄影师梦寐以求的题材。即使不摄影，站在观景台上看日出也是一次难忘的体验。

### 实操信息

|------|------|
| 地址 | 霞浦县松港街道北岐村，山顶观景台 |
| 停车 | 观景台下方有停车场，免费，约30个车位 |
| 停车坐标 | 高德搜"北岐滩涂观景台" |

| 手机信号 | 好 |
| 潮汐影响 | 退潮或半潮时最佳，⚠️ 出发前务必查询当天潮汐。满潮时滩涂被海水覆盖，看不到紫菜架 |

### 摄影机位建议

1. **山顶主观景台**：最经典机位，视野开阔，能看到大面积滩涂和紫菜架阵列。人最多，国庆要早到占位
2. **观景台左侧小路**：沿左侧有一条小路可以走到更高处，视角更广，人相对少
3. **村子下方海边**：如果退潮，可以走到滩涂边缘近距离拍竹竿和紫菜架。⚠️ 注意脚下泥滑，不要走太远

### 日出观赏 Tips

- 10月初霞浦日出约 **05:56**，但最佳光线是日出前20分钟到日出后30分钟
- 凌晨海边温度约 **19°C**，穿长袖 + 薄外套
- 带头灯或手机照明（上山路没路灯）
- 多云天比晴天更出片（云层会被染成金红色）
- 日出随缘 -- 如果天气不好别沮丧，滩涂本身在任何光线下都好看

### 国庆人流预估

- 预估人流：多（北岐是霞浦最知名景点，国庆摄影爱好者扎堆）
- 避开人流：05:00前到（越早越好），占到好位置后不要轻易离开
- 观景台容量有限（约50-80人舒适站立），国庆可能挤满
