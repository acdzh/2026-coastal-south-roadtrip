### 路线详情

- **出发**：蛇蟠岛停车场 → 三门县城（充电+早餐，约 20km）
- **上高速**：S37三门联络线 → G1523甬莞高速（往温岭方向）
- **途经**：G1523甬莞高速南下约 60km → 温岭松门/石塘出口下高速
- **石塘段**：G228国道到石塘半岛（上午游玩 2-3 小时）
- **继续南下**：原路返回高速 → G1523甬莞高速继续南下 → 经玉环、乐清湾
- **跨海段**：瓯江北口大桥 → 灵霓北堤
- **到达**：洞头岛

### 驾驶体验提示

- 🟢 **S37三门联络线+G1523甬莞高速**（三门→温岭，约 60km）：路况好，车流不大，甬莞高速是相对新的高速
- 🟡 **G228国道石塘段**（约 15km）：沿海国道，双向两车道，弯道多，限速 40-60。但风景极佳 -- 右手边就是大海，路过渔村、石屋、港口
- 🏔️ **石塘半岛沿海公路**：风景最好的一段！建议慢开，路边有多处临时停车带可以拍照
- 🟡 **G1523玉环段**（约 50km）：经过玉环，隧道渐多，注意灯光
- 🟢 **瓯江北口大桥**（约 3km）：跨海大桥，风景壮观，限速 100，不能停车
- 🏔️ **灵霓北堤**（约 14km）：连接大陆和洞头岛的海上长堤，两侧都是海，风景震撼。限速 60，可以在堤上找地方停车拍照

### 为什么来这里

石塘是浙江大陆最东端，依山而建的石屋群落是数百年渔民智慧的结晶。这里有新千年第一缕曙光纪念碑、壮美的海岸线栈道、独特的石屋建筑群，是浙江海岸线上最具辨识度的渔镇之一。

| 停车 | 石塘镇有多个停车场，曙光碑附近有公共停车场，约 10元/次 |

| 最佳到达时间 | 上午 9:00-10:00（光线最好，人还不算多） |
| 手机信号 | 好 |

### 游玩路线建议

1. **千年曙光碑** -- 先到这里打卡，中国大陆新千年第一缕曙光的纪念碑，视野开阔
2. **海边栈道** -- 从曙光碑沿海岸线栈道向南走（约 40 分钟单程），一侧是悬崖礁石，一侧是大海
3. **石塘老街+石屋群** -- 返回后在镇上闲逛，看百年石屋建筑，感受渔村生活气息
4. **对戒平台**（如果时间够）-- 网红打卡点，两块礁石形似对戒，适合拍照

### 国庆人流预估

- 预估人流：**多**（石塘是台州热门目的地，国庆人流大）
- 避开人流：上午 10:00 前到最好；走海边栈道可以避开镇上人群；往栈道南端走人会越来越少
- 停车注意：国庆期间石塘镇停车紧张，建议早到
