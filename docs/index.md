## 7天路线总览

<OverviewMap />

**路线概要**：上海 → 三门（台州）→ 石塘 → 洞头（温州）→ 苍南 → 福鼎 → 霞浦 → 武夷山 → 衢州 → 上海

去程5天沿海南下，回程2天内陆北上，全程环线不走回头路。去程走 G1522常台高速（嘉绍大桥绕开宁波）、G1523甬莞高速（沿海新线）、G15沈海高速；回程走 G1514宁上高速、G60沪昆高速内陆线。
