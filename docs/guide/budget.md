## 分项说明

### 高速通行费：0元

国庆10/1 00:00 — 10/7 24:00高速免费，7座以下小客车全程不收过路费。

正常收费参考：

| 路段 | 距离 | 正常收费 |
|------|------|----------|
| 上海 → 台州 | ~350km | ~170元 |
| 台州 → 温州 | ~200km | ~95元 |
| 温州 → 福鼎 | ~250km | ~120元 |
| 福鼎 → 霞浦 | ~100km | ~48元 |
| 霞浦 → 福州 | ~250km | ~120元 |
| 福州 → 衢州 | ~450km | ~228元 |
| 衢州 → 上海 | ~350km | ~180元 |
| **合计** | ~1950km | **~961元（全免）** |

::: warning 10/7晚注意
10/7当天必须在24:00前驶离高速出口，否则全程按正常计费。建议23:00前就近下高速再上，避免风险。走ETC通道正常抬杆不扣费。
:::

### 充电费：约435元

| 充电节点 | 预估充电量 | 费用（1.5元/kWh） |
|----------|-----------|-------------------|
| Day 2: 台州补电 | ~40kWh | 60元 |
| Day 3: 温州补电 | ~50kWh | 75元 |
| Day 4: 福鼎补电 | ~30kWh | 45元 |
| Day 5: 霞浦补电 | ~50kWh | 75元 |
| Day 6: 福州补电 | ~60kWh | 90元 |
| Day 7: 衢州补电 | ~60kWh | 90元 |
| **合计** | **~290kWh** | **~435元** |

计算依据：
- 75kWh电池，实际高速续航约450-500km（10月温度影响小）
- 全程约1950km，总耗电约290kWh
- 公共充电桩均价约1.5元/kWh（高速服务区1.6-1.8元，城区1.0-1.3元）
- 出发前家充满不计费

::: tip 省钱技巧
- 高速服务区充电最贵（1.6-1.8元/kWh），下高速到城区充电站通常便宜0.3-0.5元/kWh
- 夜间充电有谷电价（部分桩低至0.8元/kWh）
- 国庆高速服务区充电排队严重，下高速充既省钱又省时间
:::

### 餐饮费：每天普通/丰富两档

这是弹性最大的一项。海鲜丰俭由人，10月梭子蟹母蟹正肥，很难忍住不多吃几顿。

| 天数 | 行程 | 普通档 | 丰富档 | 备注 |
|------|------|--------|--------|------|
| Day 1 | 上海→台州 | 160元 | 360元 | 石塘海鲜 |
| Day 2 | 台州→温州 | 190元 | 490元 | 洞头海鲜+台州小吃 |
| Day 3 | 温州→福鼎 | 145元 | 380元 | 苍南海鲜+福鼎肉片 |
| Day 4 | 福鼎→霞浦 | 155元 | 370元 | 霞浦海鲜大餐 |
| Day 5 | 霞浦→福州 | 120元 | 370元 | 福州佛跳墙+夜市 |
| Day 6 | 福州→衢州 | 160元 | 300元 | 衢州三头一掌 |
| Day 7 | 衢州→上海 | 55元 | 110元 | 回程简餐 |
| **合计** | | **985元** | **2380元** | |

::: tip 海鲜省钱攻略
- 海鲜市场买+代加工是最划算的，加工费每道10-20元
- 避开景区正门饭店，往渔村里面走，价格差一半
- 两人不要贪多，2-3个硬菜+1个蔬菜足够
- 220V外放电+电蒸锅自己在车上蒸海鲜，最省钱最新鲜
:::

### 特产采购：200-500元

详见[美食指南 - 回程特产采购清单](./food-guide.md#回程特产采购清单)。主要采购：

- 温州鸭舌（真空包装）30-60元
- 福鼎白茶 50-200元
- 霞浦紫菜 20-50元
- 福州鱼丸/肉燕（冷冻）20-40元
- 衢州兔头/鸭头（真空包装）30-60元

### 停车费：0-100元

全程车中泊，大部分停车免费。偶尔城区收费停车预留100元。
