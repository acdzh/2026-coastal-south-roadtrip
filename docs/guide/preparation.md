# 出发前准备

## 车辆检查清单

出发前一周做一次全车检查：

- [ ] **轮胎**: 胎压、磨损情况、备胎（如有）
- [ ] **刹车**: 刹车片厚度、刹车油液位
- [ ] **灯光**: 大灯、转向灯、刹车灯、雾灯
- [ ] **雨刮**: 刮水效果，玻璃水加满
- [ ] **充电线缆**: 随车充电线、转接头检查
- [ ] **车载逆变器**: 220V外放电功能测试，确认最大功率
- [ ] **空调**: 制冷制热正常（夜间睡车可能需要）

## 纯电车专项注意

### 长下坡动能回收
- 浙闽沿海高速山区路段多长下坡，提前设置动能回收为「强」挡
- 长下坡不要持续踩刹车，利用动能回收减速更安全
- 注意电池满电时动能回收会减弱（出发前不要充到100%）

### 海边盐雾防护
- 充电口盖每次充完电都要盖紧
- 海边停车时可用保鲜膜包住充电口，防止盐雾侵蚀导致接触不良
- 每天检查充电口是否有盐渍，有的话用湿纸巾擦拭
- 靠海停车尽量选择有遮蔽的地方

### 夜间低温续航影响
- 10月浙闽沿海夜间约20-25°C（月初），不算太冷，续航影响不大
- 山区回程（衢州等）夜间可降至13-17°C，早晨出发前预热电池
- 550km实际续航在10月温度下预计保持在500km以上

### 高速充电排队应对
- 国庆高速服务区充电可能排队1-2小时
- **避开策略**: 高峰时段（10-14点）不在服务区充电，改为下高速到就近城区充电站
- 提前规划充电站，不要等到20%以下才找充电桩
- 下载多个充电App，不同服务区可能用不同平台

## App 准备

### 充电 App
- **国网e充电**: 高速服务区主力，必装
- **特来电**: 城区覆盖密集，浙闽沿线很多
- **星星充电**: 超充站较多，补充用
- **云快充**: 聚合平台，可以搜到多家的桩

> 建议至少装 3 个充电 App。不同充电站可能只接入单一平台。

### 导航
- **高德地图**: 路线规划准确，沿海公路数据好
- 沿海小路导航可能不准（显示能走但实际路很窄），遇到可疑路段先下车看看

### 其他
- **天气App**: 出行天气推荐，精确到小时
- **小红书**: 路上搜当地美食攻略
- **大众点评**: 查餐厅评分和排队情况

## ETC 和高速注意

### 国庆高速免费政策
- **免费时段**: 2026年10月1日 00:00 — 10月7日 24:00
- **适用车型**: 7座及以下小型客车
- **计时标准**: 以驶离高速出口收费站的时间为准

### ETC 注意事项
- 免费期间 ETC 正常通行，账单显示 0 元，不会多扣钱
- 如果从人工通道上高速，下高速也走人工通道（不要混走 ETC）
- 10月7日晚接近24:00时，建议就近下高速再重新上，避免过了时间按全程计费
- 提前上高速可以（9/30晚出发），只要10/1 0时后驶离出口即免费

### 沿途限速
- 浙闽高速一般限速 120km/h，隧道 60-80km/h
- 温州-福鼎段隧道密集，频繁限速变化，保持注意力
- 福建部分路段限速 100km/h
- 雨雾天气可能临时限速或封闭

### 穿衣建议
- 白天：短袖或薄长袖（沿海月初30°C+）
- 夜间/清晨：薄外套、卫衣（山区夜间16°C以下）

### 台风提醒
⚠️ 2026年台风季异常活跃，10月仍属活跃期。出发前关注中央气象台台风路径预报。如遇台风预警，沿海路段可能临时封闭，需提前调整行程。

## "路上发现好地方"决策指南

### 值得停的信号
- 看到海岸线突然开阔、有临时停车带或观景平台
- 路过小渔村/小港口，有渔船停靠、有晾晒的渔网
- 看到通往海边的小岔路（尤其是未铺装路或水泥小路）
- 路上遇到当地人在卖海鲜/水果的路边摊
- 经过无名海湾、废弃灯塔、老石屋
- 路牌上出现"XX古村"、"XX渔港"、"XX湾"等字样

### 不值得停的信号
- 看起来很"景区化"的入口（大停车场、售票亭、旅游大巴）
- 国庆期间路边停满车的地方（说明已经被发现了，不小众）

### 安全停车原则
- 只在有明确停车区域的地方停（临时停车带、路肩宽处、村庄空地）
- 不要停在弯道、隧道口、桥上
- 山路不要随意停车
