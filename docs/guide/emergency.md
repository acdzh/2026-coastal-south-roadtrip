## 保险信息提醒

出发前完成以下事项：

- [ ] 确认车险保单号，拍照保存
- [ ] 记录保险公司 **24 小时道路救援电话**（通常印在保单或 APP 首页）
- [ ] 确认救援服务范围：是否包含搭电、拖车、换胎等
- [ ] 确认拖车免费里程数（纯电车拖车需平板拖车，提前和保险确认）
- [ ] 两人均保存一份紧急联系人信息（家属电话、保单号、救援电话）

::: danger 纯电车拖车注意
纯电 SUV **禁止使用普通拖车钩拖拽**，必须使用平板救援车。叫救援时务必强调"纯电动车，需要平板拖车"。
:::

## 台风与极端天气应对

### 天气信息

- 浙江沿海 10 月气候：白天 22-27°C，夜间约 18°C，降水概率约 30%，台风风险中低
- 福建沿海 10 月气候：白天 22-28°C，夜间约 19°C，降水概率约 25%
- **出发前 3 天开始每日查看天气预报和台风路径**

### 台风监测

- 浙江台风路径实时发布系统：[https://typhoon.slt.zj.gov.cn/](https://typhoon.slt.zj.gov.cn/)
- 中央气象台台风网：[http://typhoon.nmc.cn/](http://typhoon.nmc.cn/)
- 手机 APP：中国天气、彩云天气（支持分钟级降水预报）

### 台风预警等级与行动

| 预警等级 | 颜色 | 行动建议 |
|----------|------|----------|
| IV 级 | 蓝色 | 关注路径，正常出行但避开海边景点 |
| III 级 | 黄色 | 评估是否调整路线，避开沿海路段，提前充满电 |
| II 级 | 橙色 | **停止沿海行程**，就近找安全酒店停留，车辆停至地下车库 |
| I 级 | 红色 | **立即就近避险**，不要上路，远离低洼地带和海边 |

### 暴雨天气行车要点

- 能见度低于 100m：开启双闪、雾灯，车速降至 40km/h 以下
- 积水路段：水深超过轮胎一半（约 15cm）**不要通过**，纯电车涉水虽然密封性较好，但底盘电池包不宜长时间浸泡
- 山区路段（武夷山段）：注意落石和塌方警示，保持车距

## 车辆故障应对

### 电量不足 / 趴窝

1. 打开导航搜索最近充电站，确认是否有空闲桩位
2. 开启 ECO 模式，关闭空调和不必要的电器设备
3. 电量低于 10% 时不要再坚持开，靠边停车呼叫救援
4. 拨打 **12122**（高速）或保险公司道路救援电话，要求平板拖车送至最近充电站

### 充电故障

| 问题 | 处理方式 |
|------|----------|
| 充电枪插入无反应 | 检查充电口是否有异物，尝试重新插拔；换相邻桩位尝试 |
| 充电中途断开 | 查看车辆是否报错，重新启动充电；多次失败则换站 |
| APP 无法启动充电 | 尝试扫桩上二维码；拨打对应平台客服（见上方表格） |
| 充电速度异常慢 | 可能是桩功率低或电池温度异常，高温/低温均影响充电速率 |
| 充满后无法拔枪 | 先在车内解锁充电口，再尝试拔枪；仍无法拔出则联系客服 |

### 轮胎问题

1. 感觉车辆跑偏或有异响，立即减速靠边停车
2. 开启双闪，在车后 150m（高速）或 50m（普通道路）放置三角警示牌
3. 如有备胎和工具可自行更换；纯电 SUV 通常不配备胎，检查是否有补胎液
4. 无法自行处理则拨打保险救援或 12122

### 电池 / 动力系统报警

- 仪表盘出现电池相关红色警告：**立即靠边停车**，不要继续行驶
- 闻到异味或看到冒烟：立即停车、熄火、所有人下车远离车辆至少 20m，拨打 119
- 黄色警告（非紧急）：降低车速，尽快前往最近的品牌授权服务中心检测
- 出发前记录车辆品牌 24 小时道路救援电话

### 交通事故处理

1. 确保人员安全，开启双闪，放置警示牌
2. 有人受伤：立即拨打 **120** 和 **110**
3. 轻微事故无人伤：拍照取证（车辆位置、损伤部位、对方车牌、现场全景各一张），然后将车移至不妨碍交通处
4. 拨打 **110** 报警备案
5. 联系保险公司报案
6. 异地事故理赔：保留所有票据、事故认定书，回沪后联系保险公司跟进
